# Game Planner — memoria de sugerencias

Este archivo lo mantiene el agente `game-planner` (`.claude/agents/game-planner.md`). Registra cada
recomendación que el agente ha hecho sobre qué juego portar o agregar a continuación, para no repetir
una sugerencia ya rechazada ni volver a proponer algo que ya está implementado.

No es un spec ni reemplaza `references/implemented-games.md` (que refleja el estado real del catálogo).
Este archivo refleja el _historial de recomendaciones_, independientemente de si se llevaron a cabo.

Estados posibles: `Sugerido`, `Aceptado`, `Rechazado`, `Implementado`.
